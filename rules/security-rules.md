# 安全合规红线（SSOT）

> L0 级不可逾越红线，违反即终止流程。本文件为安全红线**唯一事实源（SSOT）**；逐条机器校验见 `scripts/check-security/`（违反即拦截），指令层不重复列清单。

## 1. 数据与代码安全（true invariants，绝对禁止）

- 密钥 / Token / 密码禁止硬编码；敏感配置须通过环境变量或密钥管理系统注入
- 日志 / 输出禁止包含敏感信息（密码、Token、个人隐私）
- 禁止 `eval()` / `exec()` / 拼接 SQL 等动态代码与动态 SQL 执行
- 用户输入禁止直接拼入系统 Prompt（Prompt 注入防护）；AI 禁止访问未授权资源
- 数据库访问须参数化查询防注入；用户输入须类型 / 长度校验与 XSS 过滤；上传须校验类型与大小；URL 跳转须白名单（SSRF 防护）

## 2. 访问控制与基础设施（判据式）

- 接口须有认证与授权校验，遵循最小权限（RBAC/ABAC 按项目选配）
- 基础设施遵循平台安全基线（非 root、最小暴露、网络隔离、DDoS 防护由平台 / 运维负责）

## 3. AI 运行安全

- Agent 执行外部命令须经审批；文件系统访问须在沙箱内；网络请求须审计
- AI 禁止自行修改 Rule 约束、绕过门禁、跳过 Workflow 环节、伪造验收或审计日志
